# Schoolent

Schoolent 的临时品牌官网。当前版本以黑色、纯净、科技化的占位视觉呈现 Schoolent 的重构状态，并提供旗下在线项目入口：

- [KSC · 学生会透明门户](https://ksc.schoolent.cn)
- [Yuvek · 升学探索](https://yuvek.schoolent.cn)

## 本地运行

    npm install
    npm run dev

生产构建：

    npm run build
    npm run preview

构建结果输出到 dist/。Vite 使用相对资源路径，可部署到域名根目录或子路径。
